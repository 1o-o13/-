루트(free_pkg_1109 바로 아래) 파일 설명
폴더 설명은 각 폴더 안의 "기능 설명.txt"에 있음

[ 먼저 읽을 문서 ]
README.md           무료 버전 세트 소개. 쓰는 모델, 유료판과 달라진 점, 검증 결과, 설치 방법
CLAUDE.md           Claude Code가 이 폴더에서 일할 때 가장 먼저 읽는 개발 지시서
                    작업 원칙(버전 고정, 스키마 수정 전 승인, 개인정보 가리기), 면접 규칙, 단계별 작업과 검증
시작프롬프트.md      Claude Code를 처음 시작할 때 복사해서 붙여 넣는 첫 프롬프트
유료버전_정리.md     유료판(Claude) 모델·패키지 정리 (보관용)
                    결정: 유료로 바꾸는 건 LLM만, 임베딩은 무료 bge-m3 유지

[ 설정 ]
.env                실제 설정값과 비밀값 (DB 비밀번호, API 키, 로그인 앱 키 등)
                    저장소에 절대 올리지 않음. 남에게 보내지 말 것
.env.example        .env의 빈 칸 견본 (항목 이름만 있고 비밀값은 없음)
                    tasks.ps1 up 할 때 .env가 없으면 이걸 복사해서 만듦
                    주요 항목: LLM_PROVIDER(ollama/claude), MODULE_MODE·STT_MODE·TTS_MODE·FACE_MODE(stub/real)
.gitignore          git에 올리지 않을 것 목록 (.env, 캐시, node_modules, 개인 목소리 녹음 등)
.dockerignore       Docker 이미지 만들 때 넣지 않을 것 목록 (.env, node_modules 등)

[ 실행 (Docker Compose) ]
compose.yml          기본 실행 환경. 컨테이너 10개
                     postgres(DB), redis(작업 큐), api, worker, web(화면),
                     judge(코딩 채점), stt(음성→글), tts(면접관 음성), face(얼굴 대조), nli(답변 판별)
compose.ollama.yml   LLM 서버(Ollama) 추가용. GPU 서버에서 compose.yml과 합쳐 씀
                     qwen3:4b + qwen3:1.7b + bge-m3를 동시에 올려 둠
compose.e2e.yml      E2E(화면 전체 흐름) 시험 전용. 가짜 카메라라 얼굴 대조를 잠시 가짜로 바꿈
compose.loadtest.yml 부하 시험 전용. 모든 모듈을 가짜로 바꿔서 서버 처리량만 잼 (LLM 비용 없음)

  합쳐 쓰는 법: docker compose -f compose.yml -f compose.ollama.yml up -d

[ 작업 스크립트 ]
tasks.ps1           Makefile 대신 쓰는 PowerShell 스크립트
                    powershell -ExecutionPolicy Bypass -File tasks.ps1 <작업>
                      up     컨테이너 빌드·실행
                      seed   DB 초기화 → 스키마 → 시험 데이터 → 회사 문서 (Ollama 있으면 임베딩까지)
                             ※ 초기화 전에 직접 본 면접 기록은 records/interviews/로 먼저 빼 둠
                      test   pytest + vitest (결과는 records/test_runs.csv에 자동 기록)
                      e2e    DB 초기화 후 Playwright로 화면 전체 흐름 시험
                      bench  STT·TTS 비교 기준값 측정

[ 자동으로 생기는 폴더 ]
.pytest_cache/      pytest 캐시 (지워도 됨) - 안에 설명 있음
.ruff_cache/        Ruff 코드 검사 캐시 (지워도 됨) - 안에 설명 있음

지워도 되나
  캐시 폴더 2개만 지워도 됨
  .env는 지우면 설정·비밀값이 사라짐 (.env.example에서 다시 만들 수는 있지만 값은 다시 넣어야 함)
  나머지는 지우지 말 것
