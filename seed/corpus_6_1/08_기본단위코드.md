# 단위 코드 — 멱등성 키 확인
<!--meta: doc=UNT-PAY-01; doc_type=unit_code; tier=0; topic=PAY; disclosure=public; stages=2차-->

## 해시로 처리한 요청 기억하기
<!--meta: sec=s1; dept=BE; level=신입|주니어; ct_band=하; related=PRJ-PAY-3-->
요청 키 목록이 주어질 때, 처음 온 키는 "처리", 이미 처리한 키는 "중복"으로 출력하는 함수입니다. 해시(딕셔너리)에 키와 처음 결과를 저장해 한 번에 O(1)로 확인합니다. 만료 시간이 있는 경우는 (키, 만료 시각)을 저장하고, 조회 때 만료됐으면 새 요청으로 봅니다.

# 단위 코드 — 두 목록 대사
<!--meta: doc=UNT-PAY-02; doc_type=unit_code; tier=0; topic=PAY; disclosure=public; stages=2차-->

## 정렬 후 투 포인터로 맞춰 보기
<!--meta: sec=s1; dept=BE; level=신입|주니어; ct_band=하; related=PRJ-PAY-3-->
(승인번호, 금액) 두 목록을 승인번호로 정렬하고 두 포인터를 앞에서부터 움직입니다. 번호가 같으면 금액을 비교하고 둘 다 한 칸 이동, 다르면 작은 쪽만 이동하며 그 항목을 "한쪽에만 있음"으로 기록합니다. 전체 시간은 정렬의 O(N log N)입니다.

# 단위 코드 — 최단 경로
<!--meta: doc=UNT-PAY-03; doc_type=unit_code; tier=0; topic=PAY; disclosure=public; stages=2차-->

## 우선순위 큐로 다익스트라
<!--meta: sec=s1; dept=EMB|BE; level=주니어|시니어; ct_band=중; related=PRJ-PAY-3-->
매장·거점 그래프에서 시작점부터 각 정점까지 가장 짧은 이동 시간을 구합니다. 우선순위 큐에서 거리가 가장 작은 정점을 꺼내 이웃 거리를 줄이고, 이미 확정된 정점은 건너뜁니다. 간선 가중치가 음수가 아니어야 합니다.

# 단위 코드 — 접두어 범위 찾기
<!--meta: doc=UNT-SRC-01; doc_type=unit_code; tier=0; topic=SRC; disclosure=public; stages=2차-->

## 이분 탐색으로 자동완성 범위 구하기
<!--meta: sec=s1; dept=BE; level=신입|주니어; ct_band=하; related=PRJ-SRC-3-->
정렬된 문자열 목록에서 접두어 p로 시작하는 첫 위치는 lower_bound(p), 끝은 lower_bound(p + 가장 큰 문자)입니다. 두 번의 이분 탐색으로 O(log N)에 범위를 구하고, 범위 안에서 검색량 상위 k개를 고릅니다.

# 단위 코드 — k개 정렬 목록 합치기
<!--meta: doc=UNT-SRC-02; doc_type=unit_code; tier=0; topic=SRC; disclosure=public; stages=2차-->

## 우선순위 큐로 합치기
<!--meta: sec=s1; dept=BE|AI; level=주니어|시니어; ct_band=중; related=PRJ-SRC-3-->
각 목록의 첫 원소를 우선순위 큐에 넣고, 가장 큰 것을 꺼낼 때마다 그 목록의 다음 원소를 넣습니다. 이미 결과에 있는 ID는 해시 집합으로 건너뜁니다. 전체 O(K log k)입니다.

# 단위 코드 — 누적 높이에서 위치 찾기
<!--meta: doc=UNT-CHT-01; doc_type=unit_code; tier=0; topic=CHT; disclosure=public; stages=2차-->

## 누적 합과 이분 탐색
<!--meta: sec=s1; dept=FE; level=신입|주니어; ct_band=하; related=PRJ-CHT-3-->
메시지 높이 배열로 누적 합 배열을 만들면, 스크롤 위치 y에 있는 메시지는 누적 합이 y보다 커지는 첫 위치입니다. 이분 탐색으로 O(log N)에 찾습니다.

# 단위 코드 — 상담 배정 점수 큐
<!--meta: doc=UNT-CHT-02; doc_type=unit_code; tier=0; topic=CHT; disclosure=public; stages=2차-->

## 우선순위 큐로 배정
<!--meta: sec=s1; dept=BE; level=주니어|시니어; ct_band=중; related=PRJ-CHT-3-->
(점수, 대기 시작 시각, 상담 ID)를 우선순위 큐에 넣고 가장 높은 점수를 꺼냅니다. 점수가 시간에 따라 바뀌면 꺼낼 때 다시 계산해, 바뀌었으면 새 점수로 다시 넣습니다.

# 단위 코드 — 작업 실행 순서
<!--meta: doc=UNT-DWH-01; doc_type=unit_code; tier=0; topic=DWH; disclosure=public; stages=2차-->

## 위상 정렬
<!--meta: sec=s1; dept=DATA|BE; level=신입|주니어; ct_band=하; related=PRJ-DWH-3-->
작업마다 진입 차수를 세고, 0인 작업을 큐에 넣습니다. 하나 꺼낼 때마다 뒤 작업의 진입 차수를 1 줄여 0이 되면 큐에 넣습니다. 꺼낸 수가 전체보다 적으면 순환이 있는 것입니다.

# 단위 코드 — 슬라이딩 윈도우 평균
<!--meta: doc=UNT-IOT-01; doc_type=unit_code; tier=0; topic=IOT; disclosure=public; stages=2차-->

## 투 포인터로 창 합 유지
<!--meta: sec=s1; dept=EMB|DATA; level=신입|주니어; ct_band=하; related=PRJ-IOT-3-->
창 크기 k의 합을 유지하며 새 값이 들어오면 더하고, 창 밖으로 나간 값(k칸 전)을 뺍니다. 각 값은 한 번 더해지고 한 번 빠져 전체 O(N)입니다.

# 단위 코드 — 영향받는 설비 찾기
<!--meta: doc=UNT-IOT-02; doc_type=unit_code; tier=0; topic=IOT; disclosure=public; stages=2차-->

## BFS로 연결 설비 탐색
<!--meta: sec=s1; dept=DATA|BE; level=주니어|시니어; ct_band=중; related=PRJ-IOT-3-->
고장 설비를 큐에 넣고, 꺼낼 때마다 연결된 설비 중 방문하지 않은 것을 넣습니다. 거리 배열에 몇 단계 떨어졌는지 기록해 가까운 설비부터 알립니다.

# 단위 코드 — LRU 목록
<!--meta: doc=UNT-WEB-01; doc_type=unit_code; tier=0; topic=WEB; disclosure=public; stages=2차-->

## 해시 맵과 연결 리스트
<!--meta: sec=s1; dept=FE|BE; level=신입|주니어; ct_band=하; related=PRJ-WEB-3-->
해시 맵은 ID → 노드, 연결 리스트는 최근 순서를 갖습니다. 조회하면 노드를 맨 앞으로 옮기고, 크기를 넘으면 맨 뒤를 지웁니다. 모든 연산이 O(1)입니다.

# 단위 코드 — 기간 안 개수 세기
<!--meta: doc=UNT-DWH-02; doc_type=unit_code; tier=0; topic=DWH; disclosure=public; stages=2차-->

## 정렬된 시각에서 이분 탐색
<!--meta: sec=s1; dept=DATA|AI; level=주니어|시니어; ct_band=중; related=PRJ-DWH-3-->
시각이 정렬된 배열에서 [t−30일, t) 구간의 개수는 lower_bound(t) − lower_bound(t−30일)입니다. 예측 시점마다 이분 탐색 두 번으로 O(log N)에 구합니다.

# 단위 코드 — 실험 그룹 배정
<!--meta: doc=UNT-WEB-02; doc_type=unit_code; tier=0; topic=WEB; disclosure=public; stages=2차-->

## 해시로 고르게 나누기
<!--meta: sec=s1; dept=DATA|BE; level=신입|주니어; ct_band=하; related=PRJ-WEB-3-->
hash(실험 이름 + 사용자 ID) mod 100으로 칸을 정하고, 칸 0~49는 A, 50~99는 B로 둡니다. 같은 사용자는 항상 같은 칸이라 방문할 때마다 그룹이 바뀌지 않습니다.

# 단위 코드 — 금액 조합 최소 수수료
<!--meta: doc=UNT-PAY-04; doc_type=unit_code; tier=0; topic=PAY; disclosure=public; stages=2차-->

## DP로 환불 금액 나누기
<!--meta: sec=s1; dept=BE; level=주니어|시니어; ct_band=상; related=PRJ-PAY-3-->
dp[x] = 금액 x를 돌려줄 때 최소 수수료로 두고, 수단마다 남은 금액 한도 안에서 dp를 갱신합니다(배낭 문제와 같은 구조). 금액을 10원 단위로 줄여 상태 수를 줄입니다.

# 단위 코드 — 시나리오 순환 검사
<!--meta: doc=UNT-CHT-03; doc_type=unit_code; tier=0; topic=CHT; disclosure=public; stages=2차-->

## DFS 색칠로 순환 찾기
<!--meta: sec=s1; dept=BE|AI; level=주니어|시니어; ct_band=중; related=PRJ-CHT-3-->
노드를 흰색(안 봄)·회색(탐색 중)·검은색(끝남)으로 칠하며 DFS를 돕니다. 탐색 중에 회색 노드를 다시 만나면 순환입니다. 시작 노드에서 끝까지 흰색으로 남은 노드는 도달할 수 없는 노드입니다.
