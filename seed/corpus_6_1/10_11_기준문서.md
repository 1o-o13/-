# 직무기술서
<!--meta: doc=JD-01; doc_type=criteria; tier=0; topic=COMMON; disclosure=public; stages=2차-->

## 백엔드 (BE)
<!--meta: sec=s1; dept=BE; level=신입|주니어|시니어; ct_band=하-->
결제·검색·상담·데이터·물류 서비스의 API와 데이터 처리를 만듭니다. 필수: Java/Kotlin 또는 Python으로 API 개발, SQL과 인덱스, 트랜잭션, 자료구조·알고리즘. 우대: Kafka·Redis, 장애 대응 경험.

## 프론트엔드 (FE)
<!--meta: sec=s2; dept=FE; level=신입|주니어|시니어; ct_band=하-->
새벽마켓 웹·앱 화면, 결제창, 상담 화면을 만듭니다. 필수: TypeScript, React, 브라우저 동작 이해. 우대: 웹 성능 개선, 접근성.

## ML 엔지니어 (AI)
<!--meta: sec=s3; dept=AI; level=신입|주니어|시니어; ct_band=하-->
검색·추천 모델, 상담 요약, 설비 이상 탐지 모델을 만들고 운영합니다. 필수: Python, 머신러닝 기초, 모델 평가. 우대: 검색·추천, LLM 활용.

## 데이터 엔지니어 (DATA)
<!--meta: sec=s4; dept=DATA; level=신입|주니어|시니어; ct_band=하-->
주문·결제·행동·센서 데이터 파이프라인을 만듭니다. 필수: SQL, Python, 배치 처리. 우대: Spark, Airflow, 스트리밍.

## 임베디드 (EMB)
<!--meta: sec=s5; dept=EMB; level=신입|주니어|시니어; ct_band=하-->
매장 결제 단말과 물류센터 센서 장치의 펌웨어를 만듭니다. 필수: C/C++, MCU·RTOS 기초, 통신 인터페이스(UART·SPI). 우대: 저전력 설계, 무선 통신.

# 면접 답변 평가 루브릭

## 기술 답변 100점
<!--meta: sec=s1; dept=AI|BE|FE|EMB|DATA; level=신입|주니어|시니어; ct_band=하-->
정확성 30(개념과 사실이 맞는가) · 회사 적용 30(우리 프로젝트 상황에 맞게 풀었는가) · 깊이 25(이유·대안·한계까지 말하는가) · 구체성 15(수치·예시·경험이 있는가). 70점 이상이면 꼬리질문, 40점 미만이면 같은 질문을 한 번 더 묻는다.

# 용어집
<!--meta: doc=GLS-01; doc_type=criteria; tier=0; topic=COMMON; disclosure=public; stages=2차-->

## 결제 용어
<!--meta: sec=s1; dept=AI|BE|FE|EMB|DATA; level=신입|주니어|시니어; ct_band=하-->
승인: 카드사가 결제를 허락함. 매입: 승인된 결제를 실제 대금 청구로 확정함. 대사: 두 기록을 맞춰 보며 차이를 찾음. 멱등성: 같은 요청을 여러 번 보내도 결과가 한 번 보낸 것과 같음. 오프라인 승인: 통신 없이 단말이 먼저 승인하고 나중에 전송함.
