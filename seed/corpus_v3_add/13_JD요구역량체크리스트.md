# (가상) 새벽소프트 JD 요구역량 체크리스트

이 문서는 BE, AI, FE 세 직무의 채용 공고(JD)에 들어가는 요구 역량을 직무별 20개씩 정리한 것이다. 각 항목은 코딩 테스트에서 약점이 드러나는 방식과 연결 알고리즘 유형을 함께 적어, 3번 문제 출제의 근거로 쓴다. 화상 면접에서는 항목별 질문 방향을 참고해 실무 역량을 확인한다.

## JDC-BE-01 시간 복잡도 분석
<!--meta: doc=CRT-JDC-BE; doc_type=criteria; tier=0; topic=COMMON; dept=BE; level=신입|주니어|시니어; ct_band=하; disclosure=public-->
- 구분: 필수
- JD 문구: 입력 크기에 따라 알고리즘의 시간 복잡도를 계산하고 맞는 방법을 고를 수 있는 분.
- 역량 키워드: 시간 복잡도, time complexity, 빅오, Big-O, 입력 크기, 최적화
- 코딩 테스트 증거: 그룹5 최대 입력에서 시간 초과, 접근 오류. 코드 리뷰 '복잡도' 항목 감점.
- 약점 태그: 시간 복잡도
- 연결 알고리즘 유형: 투 포인터/슬라이딩 윈도우, 누적 합, 정렬
- 화상 면접 질문 방향: 자신이 낸 풀이의 복잡도를 스스로 계산하고, 입력이 열 배 커질 때 무엇을 바꿀지 설명하는지 본다.
