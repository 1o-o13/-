# RES-MED-01 장비 차이에 강한 학습
<!--meta: doc=RES-MED-01; doc_type=research; tier=1; topic=MED; disclosure=abstract; status=ongoing; stages=2차-->

## 가설
<!--meta: sec=s1; dept=AI|DATA; level=시니어; ct_band=상; related=PRJ-MED-1|ISS-MED-01-->
<!--forbid: 서해의료원|RES-MED|ISS-MED-->
장비 차이는 주로 영상의 "스타일"(밝기 곡선, 선명도 처리, 잡음 패턴)에서 오고, 병변의 "모양"은 장비가 달라도 유지된다. 학습 중에 스타일만 무작위로 바꾼 영상을 보여 주면, 모델이 스타일 대신 모양에 의존하게 될 것이다.

## 진행한 실험
<!--meta: sec=s2; dept=AI|DATA; level=시니어; ct_band=상; related=PRJ-MED-1|ISS-MED-01-->
<!--forbid: 서해의료원|RES-MED|ISS-MED-->
| 방법 | 처음 보는 장비에서의 결절 AUROC 하락 |
| --- | --- |
| 기존 학습 | −0.07 |
| 밝기·대비 무작위 변환 | −0.06 |
| 선명도 필터와 잡음 패턴까지 무작위 변환 | −0.04 |
| 위 방법 + 장비 구분이 어렵게 만드는 보조 학습 | −0.03 |
| 운영 중 입력 통계만 맞추는 적응 (모델 가중치는 고정) | −0.02 |

마지막 방법은 목표를 맞췄지만, 운영 중에 입력 정규화 값이 바뀌므로 "모델이 바뀐 것인가"에 대한 규제 해석이 필요합니다.

# RES-MED-02 판독의 의견 차이를 반영한 불확실성
<!--meta: doc=RES-MED-02; doc_type=research; tier=1; topic=MED; disclosure=abstract; status=ongoing; stages=2차-->

## 가설
<!--meta: sec=s1; dept=AI|FE; level=시니어; ct_band=상; related=PRJ-MED-1|ISS-MED-02-->
<!--forbid: RES-MED|ISS-MED-->
판독의들의 의견이 갈리는 정도를 학습 목표에 넣으면, 모델의 확률이 "사람도 헷갈리는 정도"를 반영하게 된다. 이렇게 만든 불확실성은 여러 모델의 예측 차이로 구한 불확실성보다 판독의에게 더 의미 있게 받아들여질 것이다.

## 진행한 실험
<!--meta: sec=s2; dept=AI|FE; level=시니어; ct_band=상; related=PRJ-MED-1|ISS-MED-02-->
<!--forbid: RES-MED|ISS-MED-->
- 다수결 라벨 대신 판독의 세 명의 판단 비율(예: 3명 중 2명이 결절)을 그대로 목표값으로 학습했습니다. 확률의 보정 오차가 0.08에서 0.03으로 줄었습니다.
- 같은 구조의 모델 다섯 개를 따로 학습해 예측이 갈리는 정도를 불확실성으로 썼습니다. 판독의 의견이 갈린 영상을 찾아내는 성능(AUROC)은 0.74였습니다.
- 두 방법을 합쳤을 때 0.81로 가장 높았지만, 추론 비용이 다섯 배가 되었습니다.

<!--forbid: RES-MED|ISS-MED-->

## 막힌 지점

# RES-MED-03 데이터 반출 없는 공동 학습
<!--meta: doc=RES-MED-03; doc_type=research; tier=1; topic=MED; disclosure=abstract; status=ongoing; stages=2차-->

## 가설
<!--meta: sec=s1; dept=AI|BE; level=시니어; ct_band=상; related=PRJ-MED-1-->
<!--forbid: RES-MED-->
각 병원이 자기 데이터로 모델을 조금씩 학습하고, 중앙 서버는 병원별 모델 변화량만 평균 내어 합치면, 데이터를 모으지 않고도 하나로 모은 데이터로 학습한 모델의 성능에 가까워질 것이다.

## 진행한 실험
<!--meta: sec=s2; dept=AI|BE; level=시니어; ct_band=상; related=PRJ-MED-1-->
<!--forbid: RES-MED-->
모의 실험으로, 보유 데이터를 장비 제조사 기준으로 네 개 "가상 병원"으로 나눠 진행했습니다.

| 방식 | 결절 AUROC |
| --- | --- |
| 데이터를 모두 모아 학습 (기준) | 0.90 |
| 병원별 변화량 단순 평균 | 0.85 |
| 병원별 데이터 양으로 가중 평균 | 0.86 |
| 각 병원의 정규화 층은 병원별로 남기고 나머지만 평균 | 0.88 |

## 사내 기술 보고서
<!--meta: sec=s3; dept=AI|BE; level=시니어; ct_band=상; related=PRJ-MED-1-->
<!--forbid: RES-MED-->
- 새벽소프트 기술보고서 MED-TR-2026-09 「장비 차이가 큰 환경의 공동 학습」: 정규화 층을 병원별로 남기는 방식이 장비 차이를 흡수하는 데 효과적이었다. 다만 새 병원이 참여할 때마다 그 병원용 정규화 층을 처음부터 맞춰야 한다.

## 막힌 지점
<!--meta: sec=s4; dept=AI|BE; level=시니어; ct_band=상; related=PRJ-MED-1-->

# RES-TKT-03 예매 오픈 접속자 예측

## 가설
<!--meta: sec=s1; dept=DATA|BE; level=시니어; ct_band=상; related=PRJ-TKT-1-->
<!--forbid: RES-TKT-->
예매 오픈 전 일주일 동안의 공연 페이지 방문 수, 알림 신청 수, 사전 대기 화면 접속 수를 보면 오픈 순간 접속자를 예측할 수 있다.

## 진행한 실험
<!--meta: sec=s2; dept=DATA|BE; level=시니어; ct_band=상; related=PRJ-TKT-1-->
<!--forbid: RES-TKT-->
지난 예매 40회로 시험했습니다. 오픈 1시간 전의 사전 대기 화면 접속 수만으로 예측했을 때 오차가 평균 18%였고, 일주일 치 지표를 함께 쓰면 11%로 줄었습니다.
