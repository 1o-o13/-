# 수상·업무 스킬 가산점 기준
<!--meta: doc=CRT-01; doc_type=criteria; tier=0; topic=COMMON; disclosure=public; stages=2차-->

## 개요
<!--meta: sec=s1; dept=AI|BE|FE|EMB|DATA; level=신입|주니어|시니어; ct_band=하-->
1차 이력서 평가의 가산점은 아래 표로만 매깁니다. 표에 없는 항목은 가산점이 없습니다. 항목 이름이 이력서마다 다르게 쓰여 있으면 가장 가까운 항목에 대응시키되, 점수는 표를 따릅니다. 가산점 합계는 최대 10점입니다.

| 구분 | 항목 | 가산점 |
| --- | --- | --- |
| 수상 | 전국 규모 프로그래밍·AI 대회 입상 (3위 이내) | 5 |
| 수상 | 전국 규모 대회 입선, 본선 진출 | 3 |
| 수상 | 교내·지역 대회 입상 | 1 |
| 업무 스킬 | 지원 부서 핵심 기술의 실무 운영 경험 1년 이상 (예: BE의 메시지 브로커 운영, FE의 대용량 Canvas 렌더링) | 3 |
| 업무 스킬 | 오픈소스 프로젝트에 병합된 기여 | 2 |
| 업무 스킬 | 장애 대응 당번 경험 (회고 문서 작성 포함) | 2 |
| 자격 | 정보처리기사 등 국가기술자격 | 1 |

# 직무기술서
<!--meta: doc=JD-01; doc_type=criteria; tier=0; topic=COMMON; disclosure=public; stages=2차-->

## 개요
<!--meta: sec=s1; dept=AI|BE|FE|EMB|DATA; level=신입|주니어|시니어; ct_band=하-->
| 부서 | 신입 | 주니어 (2~5년) | 시니어 (5년 이상) |
| --- | --- | --- | --- |
| 백엔드플랫폼팀 (BE) | API 하나를 설계·구현하고 시험할 수 있다 | 대기열·캐시·데이터베이스를 함께 쓰는 기능을 설계하고 장애를 분석할 수 있다 | 정합성과 처리량의 균형을 정하고, 여러 서비스에 걸친 구조를 결정할 수 있다 |
| 프론트엔드팀 (FE) | 실시간 데이터를 받아 화면에 표시할 수 있다 | 대용량 화면(좌석 지도, 3D 지도, 의료 영상)의 성능 문제를 찾고 고칠 수 있다 | 실패와 불확실성을 사용자에게 전달하는 화면 구조를 설계할 수 있다 |
| AI연구팀 (AI) | 주어진 데이터로 모델을 학습하고 지표로 평가할 수 있다 | 데이터 분할·불균형·누수를 스스로 점검하고 실험을 설계할 수 있다 | 현장 배포 환경의 차이를 고려한 연구 방향을 정할 수 있다 |
| 임베디드팀 (EMB) | 센서 값을 읽고 좌표계를 맞출 수 있다 | 위치 추정과 회피 기능의 오류를 분석할 수 있다 | 안전 기능의 구조와 시험 체계를 설계할 수 있다 |
| 데이터팀 (DATA) | 로그를 모아 지표를 만들 수 있다 | 이상 패턴 탐지 실험을 설계할 수 있다 | 예측과 탐지 결과를 운영 의사결정에 연결할 수 있다 |

# 기술 꼬리 질문 평가 루브릭
<!--meta: doc=RUB-01; doc_type=criteria; tier=0; topic=COMMON; disclosure=public; stages=2차-->

## 개요
<!--meta: sec=s1; dept=AI|BE|FE|EMB|DATA; level=신입|주니어|시니어; ct_band=하-->
답변 평가 LLM은 기술 답변을 100점 만점으로 매기고, 다음 단계는 코드가 정합니다. 배점은 prompts/answer_rubric.json과 같습니다.

| 항목 | 배점 | 보는 것 |
| --- | --- | --- |
| 기술 정확성 | 30 | 개념, 원인 분석, 해결 방법이 기술적으로 맞는가 |
| 회사 프로젝트 적용 가능성 | 30 | 지원자의 방식이 회사 기술 스택과 실제 장애 사례에 적용 가능한가 |
| 문제 해결 깊이 | 25 | 원인, 선택지, 트레이드오프, 결정 이유까지 설명하는가 |
| 구체성과 근거 | 15 | 본인 역할, 수치, 측정 결과로 말하는가 |

- 본 질문 70점 이상: 꼬리 1 (2급 문서 근거)
- 꼬리 1 70점 이상: 꼬리 2 (1급 문서 근거). 기술 꼬리 질문은 최대 2개
- 본 질문 40점 미만: 같은 주제로 재질문 1회
- 그 밖: 다른 주제로 넘어감
