## 4.2 STT 표시 지연 (실제 STT, 11/17)
답변 끝 → 인식 글이 화면에 뜨기까지. 실제 면접과 같은 STT 대기열에 길이별 음성을 3번씩 넣었습니다(12/12 성공).

| 답변 길이 | 인식 평균 (최대) | 화면 표시 |
|---|---|---|
| 30초 | 6.1초 (9.2초, 첫 호출) | 약 6.6초 |
| 60초 | 6.6초 | 약 7.1초 |
| 120초 | 13.9초 (14.3초) | 약 14.4초 |
| 180초 (최대) | 18.6초 (18.7초) | 약 19.1초 |
| 실제 면접 10문항 (22~126초 답변) | 평균 9.5초 (2.8~11.7초) | — |

음성 1초당 인식 약 0.1초입니다. 업로드 시간은 빼고, 동시 1명·TTS 음성으로 쟀습니다.

## 4.3 판정 (11/16)
같은 기술 답변 30개(좋음·보통·약함 각 10개)를 모델마다 3번씩 판정했습니다.

| 항목 | 외부 (Claude Sonnet 5.5) | 사내 (qwen3:4b) |
|---|---|---|
| 같은 답변 3번 점수 차 평균 | 2.7점 | 7.7점 |
| 같은 답변 3번 점수 차 최대 | 7점 | 50점 |
| 수준별 평균 (좋음·보통·약함) | 73 · 31 · 3 | 94 · 56 · 11 |
| 형식 실패 | 0 | 0 (고치기 전 37%) |
| 두 모델 점수 상관 | 0.9 | |

- **사내 모델 형식 실패를 고침:** 판정 이유를 길게 쓰다 출력 제한(700토큰)에 잘려 점수 칸까지 못 가던 문제. 사내 모델에만 글 칸 최대 길이를 고정해 형식 성공 63% → 100%, 1회 10.2초 → 7.8초.
- **꼬리질문 생성도 같은 문제:** 6번 중 5번 실패 → 5/5 성공(약 300토큰·5초).
- **판단:** 두 모델 모두 답변 수준을 구분하고 순서도 같지만(상관 0.9), 사내 모델이 후하고 더 흔들립니다. 사내 모델은 tier 1·2 근거 꼬리질문에만 쓰이므로 그대로 두고, 보정 여부는 팀이 정합니다.

# 5. 모델 비교 (서비스 모델을 고른 근거)
같은 자료로 후보 모델을 직접 돌렸습니다. 음성은 팀원이 직접 녹음한 20문장과 TTS, 얼굴은 직접 찍은 사진 40장과 공개 자료 LFW 60명입니다. **굵게** 쓴 것이 지금 서비스 모델입니다.

| 분야 | 모델 | 결과 | 판단 |
|---|---|---|---|
| STT | Qwen3-ASR-1.7B | 글자 오류 4.3% | 가장 정확하지만 GPU 4.7GB, 더 좋은 서버에서 추천 |
| STT | **faster-whisper large-v3-turbo + 용어 힌트** | 글자 오류 5.8% · 용어 91% | 지금 PC에서 가장 나음 (힌트 전 7.4%·79%) |
| STT | large-v3 · SenseVoice · moonshine | 9.4% · 10.2% · 18.8% | 탈락 |
| TTS | **Supertonic** | 글자 오류 5.0% · 3.4초 | 정확도·속도 1위 (Qwen3-TTS 36초, CosyVoice2 14초) |
| 본인 확인 | **InsightFace buffalo_l** | 본인 100% · 타인 오통과 0 · LFW 97% | 11/16 교체 (ArcFace: 본인 웹캠 80%, LFW 52%) |
| 본인 확인 | Facenet512 · GhostFaceNet | Facenet512 본인 100%·타인 오통과 0 · GhostFaceNet 타인 오통과 4 | GhostFaceNet 탈락, 서비스는 InsightFace |
| 사진 비추기 | MiniFASNet | 실제·위조 100% 구분 | 참고 (지금은 라이브니스 동작으로 대신) |
| 표정 | **지금 규칙 (MediaPipe 얼굴 계수)** | 5가지 중 가장 많이 맞힘 | HSEmotion·DeepFace보다 나음, 점수 미반영 |
| 말 끊김 | **군말·되풀이 세기 (STT 낱말 시간)** | 망설임·더듬음 8/10 | 보통·작게·자신 있게 15개는 모두 '없음' |

| 작은 목소리 | 음량 규칙 | 0/5 | 일부러 작게 말해도 2.6dB만 작아 못 가림 → 표시 제거 |
