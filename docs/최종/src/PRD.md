# 1. 왜 만드는가
2차 면접은 면접관이 지원자마다 시간을 내야 하고, 질문 수준과 평가 기준이 면접관마다 달라집니다. 화상 면접은 AI가 같은 규칙으로 질문하고 채점해서, 담당자는 근거가 붙은 결과를 보고 결정만 하게 만듭니다. 질문은 이력서, 코딩 테스트 결과, 회사의 실제 프로젝트 문서에서 나오므로 지원자마다 다르지만 규칙은 같습니다.

**합격·불합격은 언제나 사람(채용 담당자)이 정합니다.** AI는 질문을 만들고 답변을 정리·채점해 근거와 함께 보여 주는 역할까지만 합니다. 지원자에게는 응시 전에 AI가 하는 일을 알립니다(인공지능기본법의 고영향 AI 고지). {신규 11/12}

> 이 문서는 실제로 구현해 돌아가는 상태(2026-11-17)를 기준으로 썼습니다. 설계(11/4)에서 바뀐 곳은 {변경}, 새로 생긴 것은 {신규}, 뺀 것은 {삭제}로 표시하고 날짜를 붙였습니다. 실제 화면은 화면정의서, 구조와 규칙은 TRD, 시험 결과는 테스트 결과서에 있습니다.

# 4. 면접 구성
총 10문항이고, 번호는 물어본 순서입니다. 꼬리질문과 재질문도 번호를 하나씩 차지합니다.

| 번호 | 종류 | 무엇을 묻나 | 결과 |
|---|---|---|---|
| 1 | 비기술 | 이력서에 적은 경험이 실제인지 확인 | 의견 (점수 없음) |
| 2 | 비기술 | 1차 서류에서 부족하다고 본 가치(인재상 5가지 중 하나) 확인 | 의견 (점수 없음) |
| 3 | 기술 | 코딩 테스트에서 약했던 부분을 회사 프로젝트 상황으로 | 0~100점 |
| 4~10 | 기술 | 앞 주제를 더 깊게(꼬리질문) 또는 다시(재질문), 아니면 다음 회사 프로젝트 주제 | 0~100점 |

## 점수에 따라 다음 질문이 달라진다
| 답변 점수 | 다음 질문 |
|---|---|
| 70점 이상 | 같은 주제를 더 깊게 (최대 깊이 2). 꼬리질문까지 가는 주제는 면접 전체에서 2개까지 {변경 11/9} |
| 70점 이상인데 질문과 관련 없는 답 | 같은 깊이에서 범위를 좁혀 한 번 다시 (관련성 측정 0.4 미만) {신규 11/9} |
| 40~70점 | 다음 주제 |
| 40점 미만 | 같은 질문을 한 번 다시. 본 질문에서만, 주제당 1번 {변경 11/9} |
| 무응답·인식 실패·시간 초과 | 다음 주제 (0점) |

- **난이도:** 코딩 등급에 따라 상·중·하로 정하고, 그 수준에 맞는 회사 문서로 질문합니다.
- **답변 확인:** 답변이 끝나면 인식된 글을 지원자가 보고, 인식이 틀린 곳만 고친 뒤 '완료'를 누릅니다(글자 30%까지, 60초). 판정은 확인한 글로 합니다. {신규 11/11}
- **글로 답하기:** 말하기가 어려운 지원자는 응시 전에 신청하고, 담당자가 승인하면 녹음 대신 글로 답합니다. {신규 11/12}
- **주제 점수:** 얼마나 깊이 들어갔는지(0·30·60) + 40 × 평균 점수 / 100. 깊이 답할수록 높습니다.
- **최종 평가:** 내용 60 · 언어 30 · 비언어 10. 자동 검사 5개를 통과한 버전만 담당자가 확정할 수 있고, 확정한 점수만 2차 종합 점수로 넘어갑니다.
- **2차 종합:** 면접 60% + 코딩 40%. 면접 50점 미만이나 코딩 40점 미만은 과락으로 추천하지 않습니다. AI는 과락이 아닌 사람 중 모집 인원의 2배까지 '합격 추천'을 붙이고, 결정은 담당자가 합니다. {신규 11/10}
